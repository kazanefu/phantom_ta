# ゲーム体験とストーリのつながり

ゲームジャンル: 探索型2Dアクション(メトロイドヴァニア)

探索をさせる理由付けが必要 -> 核となるプレイヤーの目的: 亡霊となって記憶を失った主人公が自分の身体を探す(物理的には身体を探すが、自分を探すという意味がある)。

亡霊は、鮮明に想像できること(生前にできた記憶のあること)しか実現できない。 -> 新たなスキルの獲得 = 忘れていた記憶を取り戻す。

通常攻撃以外の魔法は**詠唱**を**スタック構造**にため、攻撃ボタンが押されたタイミングですべてをポップしていき順に発動する。途中から並列処理などの魔法(複数個を同時にポップして発動する)などが出てくることにより、主人公が使っているのは**魔法ではない**と思えるようにする。
